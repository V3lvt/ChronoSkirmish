# Chrono Skirmish

#### About
Chrono Skirmish is a vertical slice of a Unity puzzle game that turns time into a gameplay resource: players steadily experience impact of force and become slower, while blue light pillars decrease force and red ones accelerate force. Objects and puzzles require a minimum force value to interact, forcing players to choose between mobility and access to progression. Combat is deliberate: firearms need to recharge, so every shot and every step must be weighed against your current force score. The result is a compact, high-tension loop of movement, resource-management, and tactical decision-making.

#### Engine/Tools
Unity, C#, Universal Render Pipeline (URP 17.0.4), Unity Input System (1.14.0), Shader Graph, Git/GitHub, Figma, Procreate
#### Development Time
4 months | Team size: 2
#### Genre
Puzzle, Platforming, First Person Shooter
#### References Concept
Sifu (2022), Doom, Dusk (2018)
